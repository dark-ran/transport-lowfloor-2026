# 실제 저상버스 운행 검증을 위한 데이터 수집 프로토콜 — V3

이 문서는 **아직 수행하지 않은 실측 조사**의 방법과 공공자료 출처를 명시한다. 현재 저장소는 실제 저상버스 배차간격, 환자의 탑승 성공, 장애인 접근 가능한 보행경로, 병원 왕복 소요시간을 관측하지 않았다.

## 1. 우선 조사할 정적 사례

기존 `results/route_case_brief.md`의 추천 교체 노선 중 662번(개봉1동–서남병원), 343번(대치2동–삼성서울병원), 3413번(천호1동–강동경희대병원)을 후보로 한다. 각 노선의 **병원행·귀가행** 승차 정류장을 구별하고 원자료의 실제 노선ID·정류소 ID·운행 방향을 다시 확인한다. 현재 기재된 500m는 직선거리이며 보행로 거리 또는 접근성 확보를 보장하지 않는다.

## 2. 실제 운행 관측이 가능한 자료원

공식 서울시 공개 자료:

- [교통약자전용 노선별 특정정류소 접근 버스위치정보](https://data.seoul.go.kr/dataList/OA-15343/L/1/datasetView.do): 서울시 설명에 차량유형 정보가 포함된 것으로 안내되며, `getLowBusPosByRouteSt` 호출 예시가 제시되어 있다. 서비스가 현재 운영·응답하는지는 **실제 인증 질의 전까지 확인되지 않았다**.
- [서울시 버스도착 정보 조회](https://data.seoul.go.kr/dataList/OA-1091/L/1/datasetView.do): 정류소·노선별 교통약자용 도착정보 API가 안내되어 있다.
- [공공데이터포털 서울시 버스 위치 서비스](https://www.data.go.kr/data/15000332/openapi.do): 노선ID·정류소 구간을 사용하는 차량별 위치·유형 정보 제공 안내.
- [국토부 TAGO 버스 도착정보](https://www.data.go.kr/data/15098530/openapi.do): 제공 필드로 차량유형 `vehicletp`과 도착예상시간 `arrtime`을 명시. 서울시 대상 노선의 실제 적용 가능 여부는 확인해야 한다.

**인증키가 필요할 수 있으므로** 공개 API에 임의 질의를 성공한 것으로 기록하지 않는다. 계정 비밀키·차량 식별번호 원문·장기간 위치 추적 정보는 저장소에 커밋하지 않는다.

## 3. 수집할 최소 필드 및 표본 설계

| 필드 | 설명 |
|---|---|
| 수집시각(시각대 포함) | 기록 당시의 KST, 초 단위 |
| 출처 API / 버전 | 실제 호출한 엔드포인트, 버전·요청 변수 |
| 노선ID·정류소ID·정류소 순서 | 방향별로 확인, 2026 자료 갱신 시 매칭 재검토 |
| 버스 차량 유형 | 저상 여부를 API 응답 필드로 확인. 모르면 `unknown`으로 기록 |
| 도착예정·위치 관측 | 예측값과 실제 도착 관측을 구분 |
| 조사 시간대 | 평일 진료 전 오전 및 진료 후 귀가 시간대 |
| 결측·요청 실패 | API 오류/결측은 저상버스가 없었다는 증거가 아님 |

조사 예시 설계: 평일 서로 다른 날짜 3일 이상, 병원행 오전 08:00–11:00, 귀가행 오후 14:00–18:00를 개별 구간으로 관측한다. **이는 예시 조사 계획이지 관측 결과나 병원별 실제 진료시간 정보가 아니다.**

같은 차량이 연속적으로 위치 응답에 나타나는 것을 여러 운행 횟수로 세지 않는다. 최소한 개별 차량·정류소 순서·관측시각으로 중복을 제거하고, **저상 버스 실제 정류소 통과 또는 도착 여부**는 추가 원자료로 검증해야 한다. 단일 시점의 차량 위치만으로 평균 배차, 도착률, 대기시간을 계산하지 않는다.

## 4. 현장 보행 검증

대표 행정동 '중심점'을 실제 고령자의 집으로 가정하지 않는다. 각 사례는 별도로 조사한 실거주 출발점과 병원 출입문을 사용해야 한다. 횡단보도, 단차·경사, 경계석 턱낮춤, 보도 폭, 공사 장애물, 승차 가능한 정류장 접근, 병원 도착/복귀를 **양방향으로** 확인한다. 지도상의 보행경로도 현장 접근성 확인을 대체하지 않는다.

## 5. 판정 조건

실제 저상 차량의 날짜·시간별 도착 로그와 접근 가능한 양방향 보행 경로를 모두 확보하기 전에는 다음 표현을 사용하지 않는다: '환자 이동시간 절감', '저상버스 탑승확률 증가', '75개 동의 실제 수혜', '바로 시행 가능한 배차안'.

현재 주장 가능한 것은 **2025–2026 공개 정적 데이터와 연구자 가정을 이용한 교체 우선검토 노선 사전 스크리닝**이다.
