# 2025–2026년 5월 버스 승하차 실측 수요 비교 (15개 교체 후보 노선)

> 기존 정적 저상버스 의료연결 정책 연구를 보완하는 **교통카드 기록 기반 수요 진단**입니다. 고령자/장애인 수요, 실제 저상버스 운행간격, 의료 접근성 개선의 실측치가 아닙니다.

## 입력과 검증 범위

- 서울 열린데이터광장 [버스노선별 정류장별 시간대별 승하차 인원 정보](https://data.seoul.go.kr/dataList/OA-12913/F/1/datasetView.do) 2025년 5월과 2026년 5월 **원본 CSV 파일**을 CP949로 읽어 00–23시 승차·하차 합계를 계산했습니다.
- 원본 전체: 2025년 **42,301행 / 657개 노선번호**, 2026년 **43,122행 / 665개 노선번호**. 기존 15개 후보 노선은 두 자료에서 모두 확인했습니다.
- 후보 노선 승차 기록은 **3,826,516건 → 3,933,687건 (+2.8%)**입니다. 공통 표준정류장 ID만 남긴 보조 비교는 **3,826,178건 → 3,919,111건 (+2.4%)**입니다.
- 연구용 **가상 교체 슬롯 50대와 기존 배분안은 변경하지 않았습니다.** 실제 교체 결정을 승인하거나 인과 효과를 증명하는 분석이 아닙니다.
- 기초파일 SHA256: 2025년 `7c78d229f4f6c92e6ce059a050bf0cd3f2fa2a73e41a4cc6df1cfa4f878824f8`, 2026년 `071eca2a6a1f5e306a78b3b945c7b62fdaeb1dd6c8ad7647f92f0ca803c665dc`.

## 심사 해석 및 한계

1. 월간 교통카드 **승차 건수**입니다. 고유 승객 수, 고령자/장애인 승객 수, 저상버스 이용 건수, 하루 평균, 차량 1대당 실운행량을 뜻하지 않습니다.
2. 연도별 동일한 5월을 비교했지만 노선 개편·정류장 변경·배차 공급·요일 구성·공휴일 및 대외 변수를 통제하지 않았습니다. 따라서 변화율은 정책 효과가 아닙니다.
3. 같은 노선·표준정류장 ID가 여러 행에 나올 수 있습니다. 회차·방향별 기록일 수 있으므로 임의 중복 제거를 하지 않았습니다. 공통 ID 비교 역시 운행 여건을 통제한 비교는 아닙니다.
4. **수요가 큰 노선 = 고령자의 의료 접근성 개선 우선 노선**이라고 볼 수 없습니다. 기존 의료연결 점수·형평성 분석, 2025년 차량구성, 운영제약과 함께 제한적으로 활용합니다.
5. **교체 정책 집행 승인: 0/15개 노선**이라는 기존 V4 검증 상태는 유지합니다. 이 분석은 집행 적격성 확인을 대체하지 않습니다.

## 재현

`medical/historical_may_ridership.py`는 위 공식 공개 자료의 **두 원본 CSV를 사용자가 로컬에 다운로드한 후** 오프라인으로 실행합니다.

```bash
python medical/historical_may_ridership.py --may-2025 "/path/to/2025_may.csv" --may-2026 "/path/to/2026_may.csv" --gates medical/results/v4_implementation_gates.csv
```

출력은 `medical/results/historical_ridership/may_route_simplified_reproduced.csv`이며 기존 모형의 15개 배분 노선·50대 물량을 확인한 후 작성됩니다. 원본 CSV 31MB는 이 GitHub 저장소에 올리지 않았습니다. 공개한 노선별 요약 테이블은 두 파일을 로컬에서 다시 처리한 값이며, 재현 코드의 수치와 독립 비교했습니다.
