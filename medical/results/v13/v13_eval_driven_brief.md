# V13 — 최신 독립평가 85점의 실효성·사전등록 검증 개선

**고정 기준:** 공모전 전용 V1.0의 **V12 독립평가 85/100점(기술성 45/50, 공익성 40/50)**. V11 83점 대비 +2점. V13 독립평가 점수는 아직 없다. 최신 평가 원문 `transport-lowfloor-2026_독립평가_12.txt`를 전문 확인하고 시작했다.

## 가장 중요한 새 확인: 기존 GitHub에 실제 API 관측이 있었다

[`observations/vehicle_timeseries.csv`](../../../observations/vehicle_timeseries.csv)와 [`observations/vehicle_window_summary.csv`](../../../observations/vehicle_window_summary.csv)의 공개 기록에서 **2026-10-18 일요일 16시·20시, 15개 노선 × 각 2회 조회 = 30회**를 확인했다.

| API 자료 범위 | 확인된 사실 |
|---|---:|
| 전체 차종 포함 버스 위치 응답 | **262건** |
| `busType=1` 저상형 응답 | **236건** |
| 일반형 응답 | **26건** |
| 그중 제공 시각 오래된 응답 | **2건** |
| 이 관측에서 확인한 평일 | **0일** |
| 정책 후보 23개 노선 중 이 파일에 있는 노선 | **15개** |

이 수치는 **조회시점 차량 위치 응답의 구성**이며 동일 차량 반복 조회 가능성이 있다. 236/262=90.1%를 실제 탑승인원·저상차량 도착확률·전체 운행차량 점유율로 해석하거나 현장 접근성을 인정하지 않는다. 343(20 응답/저상20), 662(17/14), 3413(28/28), 5611(7/0)도 두 시점의 노선 전체 차량 위치값이다.

## 평가 지적의 실제 수정: 필수 입력 계약

V12 독립평가의 공격적 시험에서 사전등록표의 `hospital_destination`이 누락되면 다른 병원을 적은 가상행이 형식상 후보로 수용됐다. V13에서는 **병원 목적지, 방향, ARS ID, 노선·정류장 결합**을 필수 검증한다. 누락이나 불일치면 오류. 등록일·시간대·현장 승인 참조·독립검토자도 검사한다. **증빙 참조 문자열 자체가 실제 승인서나 기록 진위를 뜻하지는 않으며 후보는 여전히 미인증**. [관련 코드](../../v13_field_registry_audit.py) · [GitHub 회귀 테스트](../../test_v13_evidence.py).

V13 로컬 패키지의 15개 테스트는 PASS. 실제 병원행·귀가행 12개 조사의 `NOT_SCHEDULED / NO` 상태는 유지. **정류장 연속 저상차량 도착, 휠체어 승차성공, 병원문까지 무장애 이동 시간 = 자료 없음, 효과 NA**.

## V13으로 해결되지 않은 부분

- 주최 측 공식 분석보고서 HWP 및 참가신청서 최종 제출: 미확인/HOLD.
- 원천 2025 정적 GIS 두 CSV의 네트워크 새 다운로드 및 오프라인 전수 복원: PENDING. V12 ZIP 내부의 가공 마스크 및 2025/26 월간 원자료 재현과 분리해 보고.
- 실제 대폐차 적격차량, 운수사 운영/차고지, 조달가격/충전비, 정류장 무장애 보행비: 미확보.
- A 차량 교체/B 정류장·접근로 개선/C 저상 배차·안내 개선의 공통 실측 KPI/효과/비용: 미확보. 225/325/425억원 가상비용을 실비로 사용하지 않음.
- 현재 API는 노선 **전체 위치** 조회이지 정류장 도착시각 데이터가 아니다. 기존 [API collector](../../v4_vehicle_snapshot.py)와 [관측 감사 정책 게이트](../../../observations/policy_observed_review.json)가 요구하는 평일 7일 및 다회 조회를 충족하지 못함.
