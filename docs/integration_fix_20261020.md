# 월별 원본을 포함한 통합 재현 수정 (2026-10-20)

LOCAL-V1.0 평가에서 지적된 V11 중단을 수정했다. 점수를 새로 산정하지 않는다.

- 공간표는 ID 연결 승차량, 병원 800m 승차량, 인접 승하차 합계를 분리 출력한다. V11은 명시적인 general_hospital_800m_boardings만 원본 재계산값과 대조한다.
- V6가 옛 오표기를 분석할 때 쓰던 과거 표는 medical/raw/v3_legacy_spatial_evidence.csv로 보존했다. a68c883의 기존 공개 CSV 바이트이며 실제 API 원응답이 아니다. 재생성되는 공간표를 역사 자료로 읽지 않는다.
- V4 집행조건 검토는 정의가 같은 전체 승차량·500m 승하차 합계의 신구 열 구조를 지원한다. ID 연결량을 병원 인접량으로 치환하지 않는다.

## 실제 실행 결과

두 공식 CP949 월별 원본(2025년 5월, 2026년 5월)을 지정해 python medical/reproduce_all.py --may-2025 <원본2025> --may-2026 <원본2026> 전체 명령을 실행했다. 종료코드 0. 91개 시험 통과와 최종 검증 영수증 생성까지 완료했다. 이는 월별 옵션 없는 이전 실행과 구분된다.

공간표를 새로 생성한 이후 V6와 V4도 다시 실행해 종료코드 0을 확인했다. 23개 노선의 병원 800m 승차량은 2,261,763건이며 V11 재계산값과 일치했다. 정책 비교표의 기존 숫자 69개는 허용오차 내에서 전부 동일하다.

이 변경은 계산·재현 경로의 수정이며 실제 의료 이동시간이나 탑승 효과를 새로 입증하지 않는다. 공식 제출 PDF는 변경하지 않았다.
