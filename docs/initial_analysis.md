# 서울시 저상버스 공급 격차와 단계적 교체 배분

2026 AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전 분석 코드.
Python 3.12에서 `python -m pip install -r requirements.txt`, `python analysis.py`, `python -m unittest -v` 실행. 결과는 results. 그림은 Windows 맑은 고딕 사용.

## 정제와 지표
348행 중 인가대수 0인 13행은 비율에서 제외한다. 0/0을 저상 0%로 해석하지 않는다. 유효 335개 노선에 대해 중복 ID, 결측, 정수, 0<=저상대수<=인가대수, 원본 비율 일치를 검사한다. 노선번호의 앞자리 0을 보존한다.
전체 보유율=sum(저상대수)/sum(인가대수). 노선 평균=mean(저상대수/인가대수). 두 분모는 다르다.

## 정책 시나리오
인가대수 고정, 고상 1대->저상 1대, 대당 비용 동일, 잔여차량 모두 교체 가능을 가정한다.
- proportional: 매 단계 잔여대수 구성비에 따른 목표 누계와 현재 배정의 차이가 가장 큰 노선에 1대.
- lowest_ratio: 현재 보유율 최저 노선에 1대. 동률이면 인가대수가 큰 순, 원본 행순서.
- threshold: ceil(t*n)-l이 양수인 문턱 도달 필요대수 오름차순 배정. 노선당 가치 1, 비용 교체대수라는 문제에서 도달 노선 수의 정확해. 잔여 예산으로 어느 노선도 새로 완성할 수 없으면 미완성 필요대수가 작은 순으로 잔여 교체. 동률은 원본 행순서.
- hybrid: 저상 0대 노선에 1대씩 먼저 배정(예산 부족 시 인가대수 작은 순), 남은 예산에 threshold 적용. 0대 해소 제약이 충족된 뒤 문턱 달성 노선 수를 최대화한다. 주민 수혜나 통행편익의 최적해가 아니다.
문턱 25/50/75%, 예산 0/10/25/50/100/200대, 전체 및 8·N·서울 접두 제외 민감도. `regular`는 편의 라벨이며 공식 노선 유형 분류가 아니다.
KMeans는 인가대수와 보유율을 표준화한 탐색적 유형화. k=2..6 중 silhouette 최고값 선택, 5개 seed로 ARI 안정성 검사. 인과·예측이나 정책대상 선정 근거로 사용하지 않는다.

## 결과
인가 6,825대, 저상 5,292대(77.5385%). 0대 노선 19개, 50% 미만 59개.
50대 교체 후 전체 보유율은 모든 정책에서 78.2711%로 동일하다.
|정책|50% 미만|0대 노선|
|---|---:|---:|
|잔여대수 비례|56|17|
|최저비율 우선|56|0|
|50% 도달노선 최대|30|9|
|0대 해소 후 문턱 도달|33|0|
최저비율 우선의 최소 노선비율은 25%, hybrid는 6.67%다. hybrid가 모든 형평성 기준에서 우월하지 않다. 문턱 정책은 소규모·문턱 근처 노선을 선호한다.
